VISUAL MANUAL

アプリを世界に公開する
Claude Code → GitHub → Vercel 完全図解

コードの中身は分からなくて大丈夫。画面のとおりに進めれば、あなたのアプリに「世界中からアクセスできるURL」が発行されます。

① Claude Code→ ② GitHub→ ③ Vercel→ ④ 公開URL 🎉
1

GitHub で「コードの置き場」を作る

GitHub はコードを保管する倉庫です。まずは空っぽの棚（リポジトリ）を1つ用意します。無料です。

https://github.com/new
Repository name my-first-app
↑
好きな名前を半角英数で入力。これがあなたの倉庫の名前になります（例：my-first-app）。
○ Public（公開） ● Private（非公開）
迷ったら Private でOK。あとから変更できます。
Create repository
↑
最後にこの緑のボタンを押すと棚が完成します。

GitHub の新規リポジトリ作成画面。名前を入れて緑のボタンを押すだけ。

  1. github.com で無料アカウントを作成（メールアドレスだけで作れます）。
  2. 右上の「＋」→「New repository」をクリック。
  3. 上図のとおり名前を入れ、Create repository を押す。
2

Claude Code から倉庫へ「アップロード」する

難しいコマンドは覚えなくて大丈夫。Claude Code に日本語でお願いするだけで、自動でアップロード（push）してくれます。

ターミナル — claude
# あなたが日本語で打つ内容（これだけ）
＞ このプロジェクトを GitHub の my-first-app
   というリポジトリに push してください

# → Claude Code が自動でコマンドを実行してくれます
git init / git add / git commit / git push ...
✓ アップロード完了！
英語コマンドの意味は知らなくてOK。Claudeが代わりに打ちます。

Claude Code に日本語で頼むと、GitHubへの送信を自動で代行してくれる。

初回だけ認証を聞かれることがあります。 その場合は画面の指示に従い、GitHubアカウントでログイン（連携）すれば、以降は自動です。
3

Vercel と GitHub をつなぐ

Vercel は「倉庫のコードを自動で公開してくれる」サービスです。GitHubアカウントでそのままログインできます。

https://vercel.com/new
Continue with GitHub
↑
最初に「Continue with GitHub」でログイン。新しくパスワードを作る必要はありません。

Import Git Repository

my-first-app Import
↑
STEP1で作った倉庫を一覧から見つけ、「Import」を押します。

Vercel の Import 画面。GitHubでログイン → 自分の倉庫を選んでImport。

4

「Deploy」を押して公開する

最後のボタンを1回押すだけ。数分待つと、世界中からアクセスできるURLが生まれます。

https://vercel.com/new/configure
Framework や設定の欄はそのまま触らなくてOK。Vercelが自動で見抜いてくれます。
Deploy
↑
この青いボタンを1回押すだけ。あとは待つだけです。

設定はいじらず、青い「Deploy」を押す。これが公開のトリガー。

https://vercel.com/.../deployments
🎉

Congratulations!

https://my-first-app.vercel.app
これがあなたのアプリのURL！ note に貼るのはコレ。

数分で発行される公開URL。これをコピーして、noteの有料部分に貼る。

⚡ ここがすごい：更新が「全自動」 一度この連携を作れば、あとは Claude Code でアプリを直して GitHub に push するだけで、Vercelが自動で再公開します。URLは変わりません。購入者は常に最新版を使えます。
✓

全体の流れ（おさらい）

① Claude Code
でアプリ作成 → ② GitHub
に push → ③ Vercel
でDeploy → ④ URL発行
→ noteで販売
覚えることは1つだけ：「直す → push → 自動で公開」。この輪が回り始めれば、運用はほぼ手間ゼロになります。
画面構成は一般的な標準UIを再現した図解です。実際の画面はサービス更新で細部が変わる場合がありますが、流れは同じです。
